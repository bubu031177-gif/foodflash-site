# FoodFlash Site

## Description

FoodFlash est une page web de présentation d'un service de livraison de repas. Elle comprend une section Hero avec un titre, un message d'accueil et un bouton d'appel à l'action.

## Installation et lancement

1. Récupérez le dossier du projet sur votre ordinateur.
2. Ouvrez `index.html` dans un navigateur web.

Aucune installation de dépendances n'est nécessaire. Pour faciliter le développement, vous pouvez également ouvrir le dossier dans Visual Studio Code et lancer `index.html` avec l'extension Live Server.

## Technologies utilisées

- HTML5 pour la structure de la page
- CSS3 pour la mise en forme et le dégradé du Hero
- JavaScript pour le message de bienvenue dans la console du navigateur
